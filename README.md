# Торговий журнал

Консольна програма на Python для обліку угод: зберігає їх у базі SQLite і рахує статистику SQL-запитами.

## Що вміє
- Додавати угоди (пара, результат, дата): `add_trade_db.py`
- Автоматично запитувати категорію для нової пари
- Перевіряти введення (текст замість числа не ламає програму)
- Імпортувати старі угоди з JSON: `import_json.py` (один раз)
- Рахувати загальну статистику: кількість угод, результат, winrate, найкраща й найгірша угода, результат по парах: `stats_sql.py`
- Рахувати статистику по категоріях (JOIN двох таблиць): `stats_join.py`
- Рахувати результат по місяцях: `stats_month.py`
- Показувати пари з кількома угодами (HAVING): `stats_having.py`

## Структура бази
- `trades` (id, pair, result, trade_date)
- `instruments` (pair, category)
- Індекси за парою й датою (`make_index.py`)

## Як запустити
1. Встановити Python 3
2. `py import_json.py` (один раз, створить базу з `trades.json`)
3. `py instruments.py` (заповнить категорії)
4. `py add_trade_db.py` додає угоду
5. `py stats_sql.py`, `py stats_join.py`, `py stats_month.py` показують статистику

## Технології
Python 3, SQLite, SQL (JOIN, GROUP BY, HAVING, індекси), JSON
