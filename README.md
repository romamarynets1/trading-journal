# Торговий журнал

Консольна програма на Python для обліку угод: зберігає їх у базі SQLite і рахує статистику.

## Що вміє
- Додавати угоди (пара та результат): `add_trade_db.py`
- Імпортувати старі угоди з JSON: `import_json.py` (запускати один раз)
- Рахувати статистику SQL-запитами: кількість угод, загальний результат, winrate, найкраща й найгірша угода, результат по кожній парі: `stats_sql.py`

## Як запустити
1. Встановити Python 3
2. `py import_json.py` (один раз, створить базу з `trades.json`)
3. `py add_trade_db.py` додає угоду
4. `py stats_sql.py` показує статистику

## Технології
Python 3, SQLite, JSON
