# Торговий журнал

Консольна програма на Python для ведення журналу угод: додає угоди у файл і рахує статистику.

## Що вміє
- Додавати угоду (пара та результат): `add_trade.py`
- Рахувати статистику: кількість угод, загальний результат, winrate, найкраща й найгірша угода, результат по кожній парі: `journal.py`
- Зберігати дані у файл `trades.json`

## Як запустити
1. Встановити Python 3
2. `py add_trade.py` додає угоду
3. `py journal.py` показує статистику

## Технології
Python 3, JSON
