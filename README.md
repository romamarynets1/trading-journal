# Торговий журнал

Невеликий вебсервіс для обліку угод: база SQLite, API на FastAPI і проста вебсторінка. Окремий скрипт щодня завантажує курси валют з API Frankfurter.

## Що вміє
- Додавати, переглядати й видаляти угоди (API і вебсторінка)
- Рахувати статистику: кількість угод, результат, winrate, найкраща й найгірша угода, результат по парах
- Щодня збирати курси валют у базу без дублів (автозапуск через Планувальник завдань)
- Валідація даних на вході (Pydantic)

## API
| Метод | Адреса | Що робить |
|---|---|---|
| GET | `/trades` | Усі угоди (фільтр `?pair=EURUSD`) |
| POST | `/trades` | Додати угоду |
| DELETE | `/trades/{id}` | Видалити угоду |
| GET | `/stats` | Загальна статистика |
| GET | `/stats/by-pair` | Статистика по парах |
| GET | `/rates` | Курси валют (фільтр `?currency=EUR`) |

Автодокументація: `/docs`. Вебсторінка: `/app/`.

## Як запустити
1. Встановити Python 3
2. `py -m pip install -r requirements.txt`
3. `py import_json.py` (один раз, створює базу з `trades.json`), потім `py instruments.py`
4. `py -m uvicorn main:app --reload`
5. Відкрити `http://127.0.0.1:8000/app/`

## Технології
Python, FastAPI, SQLite, SQL (JOIN, GROUP BY, індекси), requests, HTML і JavaScript
